# 待办事项便签应用

一个简洁美观的本地待办事项管理应用，具有便签风格的界面设计。

## 功能特点

### 🎯 核心功能
- **待办事项管理**: 添加、完成、删除待办事项
- **本地数据存储**: 自动保存到本地JSON文件，数据安全私密
- **实时状态显示**: 显示总任务数和已完成任务数

### 🎨 界面特性
- **便签风格设计**: 半透明黑色主题，现代简洁
- **透明度调节**: 可通过滑块调整窗口透明度（30%-100%）
- **窗口置顶**: 支持置顶/取消置顶功能
- **自定义边框**: 圆角边框设计，可拖拽移动窗口

### 💾 数据管理
- **自动保存**: 每30秒自动保存数据
- **本地存储**: 数据保存在用户本地应用数据文件夹
- **持久化**: 应用重启后数据不会丢失

### 🪟 窗口管理
- **无边框窗口**: 现代的无边框设计
- **可调整大小**: 支持窗口大小调整
- **智能关闭**: 关闭时提供最小化到托盘或完全退出选项

## 使用方法

### 基本操作
1. **添加任务**: 在输入框中输入待办事项，按Enter键或点击"添加"按钮
2. **完成任务**: 点击任务前的复选框标记为完成
3. **删除任务**: 点击任务右侧的"删除"按钮
4. **调整透明度**: 使用右上角的透明度滑块
5. **置顶窗口**: 点击图钉图标切换置顶状态

### 数据存储
- 数据自动保存在：`%LocalAppData%\ToDoApp\todos.json`
- 支持手动触发保存（通过界面状态提示）

## 技术特性

### 开发技术
- **框架**: .NET 10.0 + WPF
- **语言**: C# 12
- **UI技术**: XAML with Modern Styling

### 代码结构
- **Models**: 数据模型（TodoItem.cs）
- **Services**: 业务逻辑（TodoService.cs, SystemTrayService.cs）
- **Views**: 用户界面（MainWindow.xaml）

### 设计模式
- **MVVM模式**: 采用Model-View-ViewModel架构思想
- **服务层**: 业务逻辑与界面分离
- **数据绑定**: 使用ObservableCollection实现数据自动更新

## 安装运行

### 环境要求
- .NET 10.0 Runtime 或更高版本
- Windows 10/11 操作系统

### 运行方式
```bash
# 进入项目目录
cd ToDoapp

# 构建项目
dotnet build

# 运行应用
dotnet run
```

### 发布应用
```bash
# 发布为独立应用
dotnet publish -c Release -r win-x64 --self-contained true

# 发布为框架依赖应用
dotnet publish -c Release
```

## 自定义功能

### 主题定制
可以通过修改MainWindow.xaml中的样式部分来自定义颜色和外观：
- 背景色: `#FF222222`
- 边框色: `#FF444444`
- 按钮样式: 可自定义背景、边框、悬停效果

### 功能扩展
- **优先级**: 可以为待办事项添加优先级字段
- **分类**: 支持任务分类和标签
- **提醒**: 添加时间提醒功能
- **导出**: 支持数据导出为CSV或其他格式

## 注意事项

1. **数据安全**: 数据仅存储在本地，请定期备份重要数据
2. **性能优化**: 大量任务时建议使用虚拟化技术
3. **兼容性**: 确保目标系统支持WPF和.NET 10.0
