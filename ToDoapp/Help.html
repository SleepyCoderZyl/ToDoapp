待办便签帮助

待办便签是一个本地运行的待办事项工具，适合记录日常任务、临时提醒和桌面便签。数据默认保存在本机，不需要联网即可使用。

本地存储 小组件模式 全局快捷键 备份恢复 提醒弹窗

快速开始

  1. 在主窗口顶部输入待办事项，按 Enter 或点击添加按钮保存。
  2. 需要截止日期时，在日期选择器中选择日期；过期任务会在列表中突出显示。
  3. 勾选任务左侧复选框可标记完成，再次取消勾选可恢复未完成。
  4. 右键任务可修改、复制、归档、恢复或永久删除，具体选项会随所在列表变化。

主要用法

添加与智能解析

在输入框中写下任务内容即可添加。使用“AI 添加”或快速添加窗口时，可以输入类似“明天提醒我交报告”的自然语言，程序会尝试识别任务标题和截止日期。

待办、归档与垃圾箱

主列表用于处理当前任务。完成后可归档，归档任务可按时间分组查看和恢复。删除后的任务会进入垃圾箱，垃圾箱内可恢复或永久删除。

小组件模式

小组件模式会以较小窗口展示待办事项，适合放在桌面边缘。可在托盘菜单或窗口按钮中切换主页面和小组件。

沉浸模式

进入沉浸模式后，小组件会减少鼠标交互干扰。需要编辑或操作任务时，可从托盘菜单或小组件右键菜单退出沉浸模式。

全局快捷键

默认快捷键为 Ctrl + Shift + Alt + Z，可唤起快速添加窗口。快捷键可在“设置”中重新配置，建议至少包含一个修饰键以减少冲突。

提醒功能

可以在设置中配置开机自启、启动提醒和每日定时提醒。定时提醒每天只会按设定时间弹出一次，内容按设置中的顺序展示。

系统托盘菜单

  • 切换到小组件 / 切换到主页面：在主窗口和小组件模式之间切换。
  • 显示 / 隐藏小组件：在小组件模式下快速控制小组件是否显示。
  • 进入 / 退出沉浸模式：在小组件模式下降低或恢复鼠标交互。
  • 导入/导出：导入 JSON 待办文件、导出当前待办，或从本地备份恢复数据。
  • 设置：调整透明度、置顶、开机自启、快捷键、提醒和启动模式。
  • 帮助：打开当前这份本地帮助页面。
  • 关于：查看版本信息并检查 GitHub Releases 更新。
  • 退出程序：完全关闭应用。

数据与备份

待办数据和设置保存在 Windows 本地用户目录下，主要位置为：

  • 待办数据：%LocalAppData%\ToDoApp\todos.json
  • 应用设置：%LocalAppData%\ToDoApp\settings.json
  • 本地备份：位于同一应用数据目录下的备份文件。

程序会在关键操作时保存数据，并保留最近的本地备份。需要迁移电脑或长期保存时，建议通过托盘菜单导出 JSON 文件。

注意事项

  • 数据仅存储在本机，卸载、清理用户数据目录或更换电脑前，请先导出重要待办。
  • 全局快捷键可能与其他软件冲突；如果快速添加窗口无法弹出，请在设置中更换组合键。
  • 开机自启和提醒弹窗依赖 Windows 当前用户环境，系统权限或安全软件可能影响启动行为。
  • “检查更新”需要访问 GitHub Releases；离线时不影响待办、备份和本地帮助页面使用。
  • 恢复备份会替换当前待办列表。执行前请确认选择的备份时间，必要时先导出当前数据。
  • 如果帮助页面无法打开，可能是 Help.html 缺失或默认浏览器配置异常。
